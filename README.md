# Ahmed Hussein — Portfolio V1

A static portfolio prototype built using HTML, CSS and vanilla JavaScript. Color scheme: navy `#101e34`, white `#ffffff`, gold `#d8ac63`.

## Preview locally

Open `index.html` in a browser, or for full local serving:

```bash
python -m http.server 8000
```

Open http://localhost:8000 in your browser.

## Publication (only after approval)

1. **Do not overwrite the live repository before approval.** Save a copy of its current content.
2. In your GitHub repository `puplichost/AHMED-HUSSEIN`, upload `index.html` and the `assets/` directory *into the repository's Pages publication folder* (normally repository root, unless configured otherwise).
3. Confirm the Pages branch/folder in GitHub Settings > Pages and wait for the new version to deploy.
4. Check https://puplichost.github.io/AHMED-HUSSEIN/ on mobile and desktop.
